NETWORK FLOW MAPS

Spine Leaf Fabric
.arch-net-spine
A two spine, four leaf datacenter fabric with server rows, packets fanning across every spine to leaf uplink. Use for clos network diagrams.
Mesh Network
.arch-net-mesh
Five fully connected peers with packets hopping edge to edge around the mesh. Use for peer to peer or full mesh overlay diagrams.
Neural Network Map
.arch-net-neural
Three node layers with weighted edges and a signal wave that lights each layer left to right. Use for model or inference flow visuals.
QUIC Multiplexed Streams
.arch-net-quic
One connection carries four independent streams that keep flowing while a single TCP lane stalls. Use to explain head of line blocking.
Packet Routing
.arch-net-route
A packet crosses a router graph, meets congestion on the top path, then reroutes along the lower path. Use for routing and failover visuals.
CDN Edge Map
.arch-net-cdn
An origin plus edge points of presence, with a request routed to the nearest edge and a cache hit glow. Use for content delivery diagrams.
BGP Peering
.arch-net-bgp
Three autonomous system clouds exchange route advertisements across bidirectional peering links. Use for interdomain and BGP diagrams.
Load Balanced Fan Out
.arch-net-lb
A balancer sprays requests to a server pool with per node throughput bars pulsing. Use for load balancer and autoscaling visuals.
Pub Sub Fabric
.arch-net-pubsub
A broker takes messages from publishers and flows them outward to subscriber groups. Use for event bus and messaging topology diagrams.
Service Mesh
.arch-net-svcmesh
A grid of services with sidecar dots and mutual TLS links pulsing between them. Use for service mesh and zero trust topology diagrams.
Ring Topology
.arch-net-ring
A token circulates a ring of six nodes, lighting each as it passes. Use for token ring, loop and circular bus network visuals.
Star Topology
.arch-net-star
A central hub with eight spokes and traffic radiating outward to each leaf node. Use for hub and spoke or central switch diagrams.
Overlay Underlay
.arch-net-overlay
A physical underlay fabric carries a dashed logical tunnel arcing above between two endpoints. Use for VPN, VXLAN and SD WAN diagrams.
Latency Heat Links
.arch-net-heat
Edges coloured by latency, with one link heating to red and traffic rerouting to a faster path. Use for SLA and latency aware routing visuals.
