Numbered List
.lst-num
A real ordered list with CSS counter markers in a hanging gutter, so wrapped lines align under the text, not the number. Hover an item and it blooms: the number swells and glows while a ring ripples outward. Switch the marker with data-style: filled circle (default, shown), ring (outline), plain (1.), zero (01, monospace) or roman (i, ii). Colour rides --c. Pure CSS, hover-only motion.

Bulleted List
.lst-bul
A real unordered list with CSS-drawn markers in a hanging gutter. Hover an item and it blooms: the marker swells and glows while a ring ripples outward. Switch the marker with data-marker: dot (default, shown), dash, chevron, square or check (a drawn tick in --pos). Colour rides --c. Pure CSS, no icon fonts, hover-only motion.
