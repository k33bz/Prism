AWS REFERENCE ARCHITECTURES

Web Hosting
.arch-aws-web
Classic scalable web stack: Route 53 to CloudFront to ALB to an EC2 Auto Scaling group and Multi-AZ RDS, with S3 for static assets.
Serverless API
.arch-aws-api
A fully managed API path: client to API Gateway to Lambda to DynamoDB, with Cognito guarding the edge and S3 for object storage.
Scheduled Job
.arch-aws-sched
A cron-style pipeline: EventBridge fires Lambda, which buffers work in SQS for a second Lambda that writes results to S3.
3-Tier in a VPC
.arch-aws-tier3
Public, app and data subnets stacked across two Availability Zones: ALB in front of EC2 with RDS beneath, all inside one VPC.
Public and Private Subnets
.arch-aws-subnets
Routing within a VPC: an Internet Gateway feeds the public subnet, and a NAT Gateway gives private-subnet EC2 outbound access.
High Availability Multi-AZ
.arch-aws-ha
Two Availability Zones behind one ELB, EC2 in each, and a primary RDS that fails over to a standby replica in the second AZ.
Event-Driven Fan-Out
.arch-aws-event
An S3 event triggers Lambda that publishes to SNS, fanning out to two SQS queues each drained by its own consumer Lambda.
Data Lake Analytics
.arch-aws-lake
A left-to-right analytics pipeline: Kinesis lands raw data in S3, Glue catalogs it, Athena queries it, QuickSight charts it.
Microservices on ECS
.arch-aws-micro
An ALB routes to three ECS services in a cluster that share a common RDS datastore and an ElastiCache layer below.
CI/CD Pipeline
.arch-aws-cicd
CodePipeline drives CodeCommit to CodeBuild to CodeDeploy onto ECS or EC2, with a highlight stepping through the active stage.
Multi-Region DR
.arch-aws-dr
Route 53 failover routes users to an active region and, on outage, to a warm standby that receives cross-region replication.
Hybrid VPN Link
.arch-aws-hybrid
An on-prem datacentre reaches private-subnet EC2 through a VPN Gateway into the VPC, the pattern for hybrid connectivity.
