CORRELATION, TIME & DISTRIBUTION PLOTS

Parallel Coordinates
.chx-pl-parcoord
Five vertical axes with one polyline per record drawing across them, one series highlighted. Use it to compare several metrics per item at once.
Quadrant Chart
.chx-pl-quad
Two axes split the plane into four labelled zones, points settle in one by one and the target quadrant is tinted. Use it for effort against impact triage.
Connected Scatter
.chx-pl-conn
Points joined in time order with the path drawing forward and an arrowhead at the latest quarter. Use it to show how two measures moved together.
Hexagonal Binning
.chx-pl-hexbin
A honeycomb of cells, each shaded by how many points fell inside it, filling in across the plane. Use it when a scatter plot has too many points to read.
Contour Plot
.chx-pl-contour
Nested level lines drawing outward from two density peaks, inner rings strongest. Use it to show where a two dimensional distribution concentrates.
Barcode Chart
.chx-pl-barcode
Dense vertical ticks per category, one per observation, drawing left to right with a band marking the middle range. Use it for compact distribution rows.
Bump Area Chart
.chx-pl-bumparea
Ranked ribbons stacked by position each week, with ribbon thickness carrying the value, crossing when the order changes. Use it for share and rank in one view.
Radial Histogram
.chx-pl-radialhist
Twenty four bins around a clock face, each bar growing outward from the ring in turn. Use it for counts by hour or by heading, where the axis wraps around.
One Dimensional Heatmap Strip
.chx-pl-heatstrip
A single row of hour cells shaded by value with a window frame sliding along it. Use it for a compact daily profile or a rolling window explainer.
Word Cloud
.chx-pl-wordcloud
Terms sized by frequency drifting into their slots, the largest one pulsing. Use it as a quick read of what dominates a corpus of tickets, tags or logs.
Range Plot
.chx-pl-range
One row per item with a bar spanning its minimum to maximum and a marker for the current value dropping in. Use it to show where today sits inside history.
Matrix Chart
.chx-pl-matrix
Categories across against categories down, with symbol size and shade carrying each pair value. Use it for overlap or co occurrence.
Small Multiples
.chx-pl-multiples
Six mini line panels on a shared scale, each trace drawing in sequence with its own delta. Use it to compare the shape of several series without overlap.
Jittered Categorical Scatter
.chx-pl-jitter
Each observation as a dot dropped into its category column with sideways jitter so points do not stack, plus a median bar. Use it instead of bars of averages.
OHLC Chart
.chx-pl-ohlc
Open high low close ticks: a vertical range with open tick left and close tick right, drawing day by day. Use it for price or cost ranges per period.
Spline Versus Straight Overlay
.chx-pl-splinevs
The same eight points joined two ways, straight segments and a smoothed curve, emphasis alternating between them. Use it to show what smoothing adds or hides.
Tile Map
.chx-pl-tilemap
A grid of equal region tiles, each labelled and shaded by value, filling in with a legend ramp beside it. Use it when real geography would distort the read.
Density Heat Strip
.chx-pl-densestrip
A horizontal ridge of thin bars rising left to right, each coloured on a ramp by its own height so peaks glow hot. Use it for event density across a day.
