RUN CHARTS & SPC RULES

Run Chart with Rules
.chx-rc-rules
A run chart that checks all four signals: a shift band and an astronomical ring light up on the data that trips them. Toggle each rule to see it fire.
Run Chart Trend Detector
.chx-rc-climb
A seven point climb trips the trend rule of five or more points moving one way. The arrow marks the run and the least squares fit shows the slope.
Run Chart Runs Test
.chx-rc-few
Two clusters cross the median just once, so the runs chip reports too few runs against the expected range: a step change signalled by clustering.
Run Chart Too Many Runs
.chx-rc-many
A saw tooth series crosses the median on almost every point, so the runs chip reports too many runs, a sign of over adjustment or oscillation.
I-MR Control Chart
.chx-rc-imr
An individuals chart with mean and limits at plus or minus 2.66 mean moving range. Points beyond a limit are ringed, a moving range strip sits beneath.
